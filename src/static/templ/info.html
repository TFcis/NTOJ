Verdicts

Verdict Full Name Conditions Explanation
AC Accepted Your program is correct!
It output the correct answer within the time and memory limits.
WA Wrong Answer Your program did not output the correct answer, but it terminated normally with code 0.
If you truly think your code is correct, contact the administrator through the Question page.
TLE Time Limit Exceeded Your program took too long to run.
If you are sure that the problem needs a longer time limit, please contact the administrator through the Question page.
MLE Memory Limit Exceeded Your program tried to use more memory than the judge allows.
If you are sure that the problem needs a higher memory limit, please contact the administrator through the Question page.
RE Runtime Error Your program did not exit with code 0.
RE Runtime Error (killed by signal) Your program failed during execution.
There are some common reasons for this result:
  1. SIGSEGV - invalid memory access (segmentation fault)
  2. SIGFPE - erroneous arithmetic operation such as divide by zero
  3. SIGABRT - abnormal termination condition
    1. double free
    2. calling abort function
    3. assert
CE Compile Error The compiler failed to compile your program.
IE Internal Error The judge is in a state of collapse.
Please contact the administrator through the Question page.
PE Presentation Error Your output does not match the test cases.
There may be extra blank lines and spaces.
